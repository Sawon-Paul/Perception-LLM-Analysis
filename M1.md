## What is in it

### `perception/fl_model.py` — section 5.2

| function | job |
|---|---|
| `get_trainable_state(model)` | the tensors a car sends to the FL server |
| `set_trainable_state(model, state)` | load an update without touching the backbone |
| `train_local(...)` | one car's local round |
| `evaluate(...)` | precision, recall, F1, mAP50 on a labelled folder |
| `load_global(path, expect_hash)` | open a checkpoint only if its hash matches the chain |
| `load_update(path, expect_hash)` | same check for a car's update |
| `state_distance(a, b)` | L2 between two updates — the 11.6 divergence plot |
| `save_update` / `state_summary` | write an update, describe one |

Measured on YOLO11: **301 tensors, 1,518,496 parameters, 5.79 MB per round**,
including 144 BatchNorm buffers.

Those buffers matter. They are registered as buffers rather than parameters, so
filtering on `named_parameters()` drops them silently and every car drifts on
normalisation while the weights look synchronised. They are included here.

### `perception/adapters.py` — section 5.3

**Adapter A** builds the on-chain report. Crop, LLM JSON and box go into one
tar; only its SHA-256 is reported. Location becomes a geohash8 cell (~38 x 19 m),
not a raw fix, so a stored report cannot be turned back into a vehicle track.

The bundle is content-addressed, which needs determinism: no clock reading in
the metadata and no mtimes in the archive. The first version had both, and the
same evidence hashed differently on every rebuild — the hash on-chain would
never have matched the file. Fixed and tested a second apart.

**Adapter B** writes the labels for the next FL round. A verified box is
written; a rejected one is not; a frame with no verified boxes gets an empty
label file. That empty file is the teaching signal — it is what took detections
from 366 to 27.

It also appends to `sample_manifest.csv`, and `samples_for_fault(fault_id)`
reads it back. Without that, sample unlearning cannot find which frames came
from a fault that later turned out to be fake.
